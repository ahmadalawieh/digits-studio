# Digits Studio — professional portfolio direction, 26 October 2026

Audience: business owners in Lebanon and overseas seeking a credible partner for brand identity, a website or a launch. Primary task: understand the offer, inspect work, and start a qualified conversation.

Research: Koto (https://koto.com/) and PORTO ROCHA (https://www.portorocha.com/) put project-specific narratives and identities ahead of generic service claims. ON describes Koto's site as both a portfolio and a new-business tool, and stresses media optimization (https://madebyon.com/case-studies/koto-studio/). NN/g recommends motion that clarifies interactions and avoids consuming attention without purpose (https://www.nngroup.com/articles/animation-usability/).

Diagnosis: too many identical grids, identical campaign compositions, repeated generated photographs, repeated concept disclaimers in product copy, and tiny generic brand boards. Client projects open in minimal dialogs rather than meaningful case studies. The hero shows only an investor site, which obscures the broader offer. More effects alone will not resolve those problems.

Palette: signature yellow #FFDA46; ink #292A32; paper #F8F8F4; muted #68686C; white #FFFFFF; lavender #DCD6F3 used sparingly. Keep the existing Digits identity.
Typography: Archivo 650–800 for a compact studio voice; Instrument Sans 400–600 for body, labels and navigation; IBM Plex Sans Arabic for connected, readable RTL text with no tracking. Avoid uppercase eyebrows and decorative microcopy.
Layout: compact header > bold offer and live rotating project canvas > editorial project grid with meaningful category filters > three service rows with real examples > founder/direct collaboration > scope/review/launch > concise FAQ > guided project inquiry. Seven existing sections remain, with stronger hierarchy and less repetition. Project figures carry the visual character; studio chrome remains quiet.

Hero wireframe: [Beirut / working worldwide] [Branding that belongs. / Websites that bring it to life.] [short value proposition + Start a conversation] [large interactive project-stage: brand work, website, campaign].
Case-study wireframe: [name / exact scope / honest status] [large project-specific cover] [brief + approach] [identity in use] [actual website capture + demo] [campaign assets] [next project + inquiry]. Three actual projects retain their existing identities and receive accurate website case studies. Four self-initiated concepts get expanded original brand systems. Never imply that speculative identities or campaigns were commissioned by existing clients.

Distinct concept treatments: Fornaya uses a bakery menu and oversized oxblood wordmark; Riwa Grove uses a precise olive-bottle and label system with quiet sage surfaces; Dar Saha uses cobalt architectural framing, editorial photography and a stay-planning panel; Paceform uses a bold typographic campaign system, class information and direct utility. Replace synthetic lifestyle scenes with licensed photographs, credited as reference imagery; build identity applications deterministically from original vector marks so logos remain consistent. Do not represent stock photographs as actual premises, staff or products.

Motion: one composed hero arrival; project-stage crossfade with explicit previous/next and pause controls; short filter transitions preserving keyboard focus; restrained image movement only on fine-pointer hover; accordion height transitions; complete reduced-motion behavior. No cursor replacement, scroll hijacking, reveal-on-scroll walls or looping decorative marquees.

Plan critique: a cream-plus-serif treatment for all four concepts would repeat the current sameness. Reserve serif display for the oil and hospitality concepts, use markedly different layouts, and give campaigns their own type-led compositions. Avoid making every service another full duplicate of the portfolio: show compact examples that link directly into the corresponding case section.
